# Hotel Booking Data Analysis | Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of hotel booking data using Python. The objective is to explore hotel booking patterns, analyze occupancy and revenue performance, and identify meaningful business insights from the available datasets.

## Objectives

- Understand hotel booking trends and patterns.
- Analyze hotel occupancy across different cities.
- Explore revenue performance.
- Analyze booking platforms and customer behavior.
- Clean and transform raw datasets.
- Identify useful business insights through data analysis and visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Datasets

The project uses six CSV datasets:

| Dataset | Description |
|---|---|
| dim_date.csv | Date-related information |
| dim_hotels.csv | Hotel information |
| dim_rooms.csv | Room category information |
| fact_aggregated_bookings.csv | Aggregated booking information |
| fact_bookings.csv | Individual booking information |
| new_data_august.csv | Additional August booking data |

## Analysis Performed

1. Data loading and exploration
2. Data cleaning and preprocessing
3. Handling missing values and invalid records
4. Identifying and handling outliers
5. Data type conversion
6. Merging multiple datasets
7. Exploratory analysis of hotel bookings
8. Data visualization

## Key Business Questions

- Which cities have higher hotel occupancy?
- Which room categories have better occupancy?
- How does hotel revenue vary?
- Which booking platforms generate more bookings?
- What are the booking trends over time?

## How to Run This Project

1. Clone or download this repository.
2. Install the required Python libraries.

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open the project folder.
4. Launch Jupyter Notebook.

```bash
jupyter notebook
```

5. Open the notebook inside the `notebooks` folder.
6. Run the cells sequentially.
